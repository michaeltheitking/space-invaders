# Architecture and design decisions

## Decision record contract

Record architecture, provider, schema, authentication, security, deployment, and testing-policy choices here.
Do not create decisions for routine formatting, minor fixes, or task progress.
Update an existing decision when it changes; link any replacement and mark the old record superseded.
Preserve existing numbering. Choose the next unused number for a new `NNNN-short-title.md` record.

Each decision includes:

- Status and decision date.
- Context and source evidence.
- Decision and scope.
- Rationale and alternatives considered.
- Consequences and operating constraints.
- Revisit triggers and related records.

No architecture decisions are recorded here yet. Do not invent historical decisions.
